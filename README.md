## 仓库内容

- `prompts/<作品>/` —— 一件作品一个目录：`prompt.md`（提示词与参数）、`meta.json`（模型、种子等元数据）、`workflow.json`（ComfyUI 工作流）、`01.png` 等成图 / `sample.mp4` 示例视频；

- `_templates/` —— 新增作品用的模板；
